# 两分钟评审导读

## 一句话定位

本项目在一条事前固定的
“NFP 首次发布创新 → 政策路径重定价 → 实际利率重定价 → 黄金重定价”链上，使用多测量潜变量估计条件
跳转概率，联合传播参数、测量、相关性、制度漂移和外部竞争风险，并用可执行停止规则决定是否继续推理及
是否交易。

## 系统真正计算什么

三个事件分别记作 `E1/E2/E3`。模型估计的是：

```text
P_intrinsic = P(E1) × P(E2 | E1) × P(E3 | E1,E2)
P_realized  = E[(1-q) × P_intrinsic]
```

第 2、3 跳只在前缀已经成功的开发风险集中估计，不是三个无条件命中率的朴素连乘。一次后验模拟共同抽取
每跳系数、潜变量测量误差、跨跳共同 frailty、制度漂移和外部截断 `q`，由此得到中心概率和 90% CI。

## 四组必须分开的概念

### 1. 主链与诊断变量

只有固定三跳主链进入 `P_realized`。通胀预期和美元用于开发集结构回归，帮助判断遗漏解释是否重要；它们
目前不作为可替代路径进入每跳 `p_i`、链级聚合或路径择优。因此本项目是“固定主链 + 诊断变量”，不是
完整多路径图推理器。

### 2. 主测量与代理

政策路径、实际利率和黄金都是潜在经济状态。主测量固定标签尺度，代理帮助估计测量噪声和敏感性。无论
代理表现多好，都不能在看到确认结果后替换主测量。多测量提高的是可解释的不确定性表达，不等于增加历史
样本或创建新的因果路径。

### 3. 链内断裂与外部截断

链内断裂表示前因出现后，指定传导没有在下一跳继续；`q` 表示其他宏观、地缘或流动性事件覆盖原链的竞争
风险。二者分别输出。当前开发集没有独立确认的外部截断事件，因此 `q` 的后验主要由弱正则先验约束；本版
证明的是语义分离、计算接口和敏感性传播，不声称已经精确识别真实截断频率。

### 4. 停止与模型有效性

停止回答“按冻结效用和复核成本，现有证据是否值得继续行动”，不是在宣判某条因果边永久不存在。首次
非 `CONTINUE` 是实际执行点，后续跳只为复算和事后核验而保留，并标为反事实。模型有效性由历史 Brier、
可靠性、CI 检验和未来前瞻样本共同评价，不能由一次停止决定。

## 数据与证据量怎样理解

- 2011–2024 年的 164 条记录是**同一固定拓扑的 164 个事件实例**，不是 164 种不同因果链；
- 每跳 `n_raw=69/23/16` 是开发集条件风险集规模；
- `n_eff=63.51/21.06/14.86` 是时间权重经 Kish 公式得到的有效证据量，不是模拟次数或代理数量；
- 三个风险集均不少于 5，未触发稀有事件参考类回退；
- 月度事件可能存在序列相关，年份区块 bootstrap 只用于模型比较的不确定性分析。

## 如何理解区间与当期演示

90% CI 描述未知链概率的认识论不确定性，不是未来黄金收益率的价格区间，也不保证单个二元结果“落在区间
内”。合成 oracle 验证的是在已知数据生成过程下的覆盖性质；真实历史上的 CI 宽度—误差正相关验证区间
是否携带有效的不确定性排序。二者不能互相替代。

2026-09-04 NFP 是当期工作流演示：根输入发布后，系统在下游日终结果形成前输出了逐跳概率、链级 CI、
停止和交易动作。它证明端到端流程和时间顺序，不以一个尚未完成追踪的事件证明预测胜负。

## 结果应当怎样表述

主模型 Brier 为 0.1193，优于题面朴素边际连乘的 0.1284，但略差于 climatology、primary-only 和 direct
terminal logistic，并存在整体低估。因而最准确的结论是：

> 当前模型证明了非朴素条件聚合、认识论 CI、逐跳证据溯源和规则化弃权可以在真实宏观链上端到端运行；
> 它没有证明复杂模型拥有最优点预测，也没有完成自动因果发现或任意图结构推理。
