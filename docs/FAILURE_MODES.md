# 失败与边界条件

- **根信号不完整**：非农同时含工资、失业率与修订。headline innovation 方向可能不代表市场解释；
- **同时测量而非时序因果**：2Y、breakeven、real yield 和 gold 在同一交易日共同反应，日频不能证明
  每个节点按钟表顺序发生；
- **代理相关**：ZT、TIP、GC 与 ETF 共享利率/美元冲击。残差协方差和有效样本量修正只能缓解重复计数；
- **制度漂移**：零利率、疫情、激进加息等时期使系数改变；模型扩大远期 CI，但不保证中心无偏；
- **厚尾与跳空**：黄金日收益非 Gaussian；Student-t 测量权重与 oracle 厚尾场景用于压力测试；
- **外部截断**：战争、央行消息、流动性冲击可能覆盖链路。必须标为 competing risk，不得算内生失败；
- **稀少条件风险集**：少于 5 时强制参考类；参考类仍可能结构不匹配；
- **低基准率假象**：Brier `<0.15` 可能只因终点稀少，故同时比较 climatology、always-zero、朴素连乘
  和 Brier skill，并设置终点正例数量门槛；
- **确认独立性**：本地已有原始价格历史，协议先于事件对齐标签，但证据弱于真正第三方托管 holdout；
  该限制必须披露，不能用自签文件伪装为托管；
- **真实当期演示的时序污染**：若模型输出形成时任一目标下游窗口已经完成，该事件只能作为历史回放；
  根节点 actual 是模型输入，可以先于预测被观察，不应与待验证的下游 outcome 混为一谈；
- **弃权不等于模型报错**：宽 CI 和低 EVSI 可以触发 `STOP_ABSTAIN`。它表示当前证据不支持稳健行动；
  但若大量事件持续在第一跳弃权，则说明可操作覆盖率不足，必须单独报告；
- **书面规则与代码不一致**：precommit 中的盈亏阈值或最大 CI 宽度若不等于可执行配置，必须在发布前
  拒绝，不能只在文档中声明一个更保守的阈值；
- **停止后继续的语义错误**：首个停止动作之后仍可计算完整前缀供审计，但必须明确标成反事实，不能把
  最后一跳状态冒充实际执行结果；
- **提交包隐藏依赖**：本机缓存通过不等于 GitHub 干净克隆通过。被 `.gitignore` 排除但又被测试或
  precommit 哈希引用的文件会导致复现失败，必须纳入可分发提交或移除依赖。
