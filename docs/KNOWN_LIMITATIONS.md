# 已知限制与解释边界

## 预测性能

- 主模型 Brier 为 0.11928，优于朴素边际连乘 0.12843，但略差于确认集 climatology 0.11862、
  primary-only 0.11745 和 direct terminal logistic 0.11655；
- 主模型平均预测约 0.0698，确认集实际三跳率为 0.1341，存在整体低估；
- 可靠性 10 桶中存在较大偏差。例如部分中段桶的实际成功率高于平均预测概率。Wilson 区间表达有限
  样本噪声，但不能消除中心偏差；
- 当前版本不在同一确认集上执行事后校准，否则会破坏确认评估的解释。

## 因果与数据

- 主标签采用上一有效收盘到发布日收盘的日频变化，能够统一覆盖较长历史，但会混入发布后其他新闻；
- 潜变量能表达测量误差与代理相关性，诊断变量能暴露可能的竞争解释，外部截断 `q` 能传播独立竞争风险；
  三者都不能把共同市场反应自动升级为严格结构因果证明；
- 通胀预期与美元目前只进入结构诊断，不进入主链每跳 `p_i` 或链级路径聚合；当前实现不是完整多路径图推理器；
- 所谓“动态”是事件时间权重和制度漂移方差，不是带显式状态转移的完整动态贝叶斯网络；
- 非农 headline 未显式纳入工资、失业率和前值修订，市场可能基于整套报告而非 headline 交易；
- Yahoo 派生代理的完整原始长历史未在仓库再分发，复核依赖事件级派生量、来源 URL、抓取时间和哈希。

## 评估独立性

- 协议锁先于 2011–2024 事件相对标签生成，但操作者能够访问原始历史价格；
- 因此当前确认批不应描述为第三方托管的 pristine holdout；
- 164 个确认事件是同一固定三跳拓扑的重复实例，不是 164 种链结构；它们不能继续用于调参或修复整体
  低估。任何模型改进都应建立新版本并用新数据评估。

## 当期演示

- A004 的根输入 actual=162 千人在模型预测前已知；这是预期设计，因为 actual 是链的输入，不是待预测的
  下游标签；
- 预测在当日 14:03:26 UTC 形成记录，最早下游日终窗口在 20:00 UTC 完成；
- 完整 Git 历史可直接读取该 commit；浅克隆或源码压缩包不含旧 commit 时，验证器改用仓库内同一预测
  快照和预记录 SHA-256 复核数值，但 commit 时间仍来自当期记录中的声明；
- A004 当前仍是 `outcomes_unresolved`，不能用来声称已经验证该次传导是否成功；
- 一个当期事件只能演示流程，不能单独验证总体校准。

## 停止规则

- `STOP_ABSTAIN` 是有意设计的安全输出，并非运行异常；
- EVSI 是“一次等价证据复核”的简化价值计算，不覆盖所有可能的新信息或更长等待策略；
- 若未来前瞻记录频繁在第一跳弃权，模型即使校准尚可，也可能缺乏实用覆盖率。六个月追踪必须同时报告
  弃权率和停止跳位，不能只保留产生交易的事件。
