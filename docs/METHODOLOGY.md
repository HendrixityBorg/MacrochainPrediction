# 方法说明：事件索引多测量潜变量条件链

## 1. 任务对象

项目不是证明某次宏观数据必然令黄金上涨或下跌，也不是自动发现因果图或给任意 graph 打分。它估计一条事先定义的宏观
机制链在当前证据与制度下完整实现的概率、认识论不确定性以及何时应停止继续推理。一次宏观发布
是一条独立样本；代理、分支和前缀不增加样本数。

审计主链为：

```text
宏观意外 S → 政策路径 M → 实际贴现率 R → 黄金 G
```

开发/确认使用非农根事件，是因为同一宏观—利率—黄金结构能提供一个此前未生成事件标签的
2011–2024 大批次。真实当期演示也使用 2026-09-04 NFP，使根变量、尺度和传导域与历史模型一致。
通胀预期 `Π` 与美元 `D` 另作结构诊断，安全港和其他同时冲击作为限制解释；它们不进入固定三跳的
`p_i` 或链级路径聚合。历史验证中的 164 条记录是这一拓扑的 164 个事件实例，不是 164 种链结构。

本文使用“条件贝叶斯链”表示概率参数具有先验并通过开发证据更新。所谓时间动态仅指事件时间权重和从
开发期到目标日的制度漂移方差；当前版本不是带显式状态转移、滤波和任意拓扑的完整动态贝叶斯网络。

## 2. 为什么是多测量潜变量模型

“政策路径”不是 2 年期收益率本身，“实际贴现率”也不等于 TIP ETF。每个主链经济状态由多种带噪声
的市场读数测量：

| 状态 | 主测量 | 代理/敏感性 |
|---|---|---|
| 政策路径 M | H.15 2Y yield | H.15 1Y、反向 ZT return |
| 实际贴现率 R | H.15 5Y real yield | H.15 10Y real、反向 TIP return |
| 黄金 G | GLD return | GC continuous future return |

结构诊断另使用通胀预期 `Π`（5Y/10Y breakeven）和美元 `D`（DXY/UUP）。这些读数用于开发集回归，
检查 `R ~ M + Π` 与 `G ~ R + D` 中竞争解释的重要性，但不生成可替代主路径。多测量节点与多路径是两件
不同的事：前者是同一状态的测量模型，后者需要把多条拓扑显式纳入联合概率；本版本只实现前者。

对状态 `X_t`：

```text
y_jt = alpha_j + lambda_j X_t + epsilon_jt
epsilon_t ~ N(0, Sigma)
```

主测量的 `alpha=0, lambda=1` 固定尺度与符号；代理 loading、截距及残差协方差仅在开发集估计。
`Sigma` 保留代理相关性并向对角阵收缩。黄金行用 Student-t 权重降低极端日对 loading 的支配。
缺失代理被积分掉，不做均值填补。主测量缺失则不能进入主评估。

潜在状态后验：

```text
V_t = (V0^-1 + lambda'Omega^-1 lambda)^-1
m_t = V_t lambda'Omega^-1 (y_t-alpha)
```

由 `N(m_t,V_t)` 计算方向与 `1σ` 材料性成立的软概率。最终 outcome 仍由主测量硬标签决定，防止
在看到结果后挑选更有利的代理。

## 3. 带时间折扣与漂移的条件贝叶斯链

每跳使用：

```text
logit(p_it) = x_t' beta_i
beta_i ~ Normal(0, prior)
```

`x_t=[1, log(1+|root_z|), sign(root_z)]` 全部在根发布时可得。第 2 跳只使用主标签第 1 跳成功的
开发风险集；第 3 跳只使用前两跳成功的风险集。fractional Bernoulli likelihood 吸收潜变量软标签；
MAP 与观测信息矩阵给出 Laplace 后验。时间折扣决定 `n_eff`；确认日期距开发末端越远，预注册状态
漂移方差越大，所以 CI 能表达制度外推风险。

若某风险集 `<5`，不得计算小样本频率。代码改用同一宏观主题、同一跳的完整开发参考类并记录全部
事件 ID、先验、系数、协方差、随机种子和估计法。当前 NFP 跳点本身不是少于 5 次的稀有事件，仍
如实报告三个条件风险集的 69/23/16 个已知开发结果。由于没有触发 `<5` fallback，题面针对稀有
事件估计法的“另取 ≥20 条同类事件校准”条款不适用；不能把第三跳的 16 个条件实例写成 20。

三个跳点残差在开发集估计相关矩阵，并以共同 frailty 进入同一次后验抽样。因此模型没有把代理或
跳点当独立证据。链规则是：

```text
P_intrinsic = P(E1) P(E2|E1) P(E3|E1,E2)
P_realized  = E[(1-q) P_intrinsic]
```

`q` 是外部截断/竞争风险。外部截断样本不被伪装为内生边失败；输出同时给出 intrinsic、q 与
realized 概率。未计划截断使用 `Beta(1,19)` 弱正则先验，再与开发集中显式标记的截断次数合并；
当前 69 个开发事件没有显式截断，后验为 `Beta(1,88)`。这一先验不属于任何 `p_i` 的证据量，必须
在报告中单列，并用 `q=0%/1.12%/5%/10%` 敏感性说明它对链概率中心的影响。因为现有数据没有独立
确认的截断事件，`q` 主要由先验约束；本版验证其语义分离、计算接口和敏感性传播，不把后验均值声称为
已被历史充分识别的真实截断频率。

## 4. CI 的含义

90% CI 是“我们对真实链概率有多不确定”，而非终点 0/1 自身的预测区间。每次 Monte Carlo 同时
抽取：

- loading/残差所诱发的测量误差；
- 每跳结构系数；
- 跨跳共同 frailty；
- 从开发末端到目标日的制度漂移；
- 外部截断概率。

报告用 one-block-at-a-time 方差比说明来源；因为交互存在，比例不要求机械相加为 1。严禁链内乱序
bootstrap 和“多个模型的分歧当 CI”。合成 oracle 在隐藏真概率下单独验证覆盖率与宽度—误差关系。

## 5. 停止规则

盈亏平衡概率：

```text
tau = (failure_loss + transaction_cost) / (success_gain + failure_loss)
```

每个前缀计算 90% CI 和一次等价证据复核的 EVSI。规则按优先级执行：上沿低于 `tau` 拒绝；终点
下沿高于 `tau` 接受；终点跨阈值弃权；非终点只有 EVSI 高于复核成本才继续；宽 CI 但 EVSI 不足时
停止。`maximum_hops` 仅防失控，绝不是唯一理由。首个非 `CONTINUE` 状态写入 `execution_stop`；
后续前缀仍为满足逐跳审计而计算，但标记成 `counterfactual_after_stop`，不能覆盖首停决策。

第一跳出现 `STOP_ABSTAIN` 时，其含义是执行层无法在当前不确定性和复核成本下证明继续的价值，而不是
结构层宣告“第一条边不存在”。以 2026-09-04 NFP 为例：`p1=0.4031`，传播共同不确定性后的前缀中心
为 0.3984，但 90% CI `[0.1849, 0.6432]` 跨过 0.208 的盈亏阈值且宽度 0.4583 超过 0.30；其保守
效用为负。一次等价复核的 EVSI 约为 0，低于 0.01 的成本，因此选择弃权。EVSI 只描述代码中预设的
一次等价证据复核，不应被扩张解释为“任何新市场信息都没有价值”。

收益、失败损失、交易成本和复核成本是发布前配置的规范化效用，不是历史 P&L 拟合值；停止规则表达
的是这套效用设定下的一致行动纪律。precommit 的书面阈值必须与上述效用参数一致。当前固定参数给出 `tau=0.208`。真实当期演示按
“发布前固定方法与窗口—发布根输入—生成预测—下游 outcome 后产生”的时间顺序核验。

## 6. 验证设计

- 2005–2010：开发和估计法 track record；
- 2011–2024：同一固定拓扑的 164 个 confirmation event instances；模型不读取任何批内 outcome；
- baselines：always zero、climatology、边际朴素连乘、条件 Beta、primary-only、proxy-only、
  no-root；
- 合成 oracle：1–6 跳、代理相关/有效样本损失、制度漂移、黄金厚尾、外部截断；
- 机器检查：N、Brier、可靠性、逐跳衰减、CI 覆盖、CI 宽度—误差、证据更新方向、三跳复算、
  可验证时间顺序、当期演示和隔离复现必须同时有证据；历史标签接触边界必须完整披露。

## 7. 不能声称的内容

日频事件研究不能单独识别完整结构因果；潜变量降低的是测量误差，不会消除遗漏变量。系统也不声称完成
自动因果发现、任意图执行或多路径择优。非农的工资、失业率与修订同批发布，本版本的根创新不是商业
共识。黄金的美元、安全港与央行需求路径只能作为诊断或限制因素讨论，不能在失败后任意调用来“解释
正确”。当期演示证明流程按时间顺序可运行，不以单个事件证明点预测胜负；停止是执行层弃权，不是对
结构边或模型有效性的单样本裁决。
