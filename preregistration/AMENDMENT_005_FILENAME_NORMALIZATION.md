# Amendment 005：文档文件名规范化

## 目的

为降低评审入口中的语言标签噪声，仓库内中文 Markdown 文件统一移除文件名中的 `.zh-CN`。本次变更同时
修正文档链接、报告生成路径、工程门控路径和测试路径。

## 不变项

本修订只改变文件路径和相关工程引用，不改变：

- 任何历史事件、主测量、代理测量或 outcome；
- 开发期与确认期边界；
- 三跳拓扑、标签定义、模型公式、先验或参数；
- 任何 `p_i`、`n_i`、链概率、CI、Brier、可靠性或停止结果；
- 当期演示的根输入、预测时间、决策规则或既有预测快照。

历史 `PROTOCOL_LOCK` 和 `lock_history` JSON 中出现的旧文件名是原始时间戳记录的一部分，不执行文本替换。
当前锁在本修订后使用新路径重新计算；旧锁与旧时间戳继续保留，用于核验变更前的审计链。

## 新命名规则

- 中文文档继续使用中文内容，但文件名不再携带语言后缀；
- 生成报告固定写入 `reports/SUBMISSION_REPORT.md` 和 `reports/DATA_QUALITY_REPORT.md`；
- 当期中文运行记录固定写入 `demo/runs/<event_id>.md`；
- 评审入口和机器门控只引用新路径。
